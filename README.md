## Olá

Se você chegou aqui para explorar meus repositórios, este README é só a porta de entrada.

Uso este espaço para reunir projetos, estudos, provas de conceito e soluções práticas que ficam entre engenharia de dados, automação, analytics e desenvolvimento de produtos internos.

## O que você vai encontrar por aqui

- Projetos de engenharia de dados, ETL/ELT, integrações e organização de pipelines.
- Ferramentas e automações voltadas para reduzir trabalho manual e melhorar operação.
- APIs, aplicações web e experimentos que conectam dados com uso no dia a dia.
- Estudos e side projects onde testo novas ideias, stacks e abordagens.

## Temas que aparecem bastante nos meus projetos

- Python, SQL, AWS, SAP HANA, Redshift, Airflow e automação analítica.
- FastAPI, Node.js, React e aplicações internas orientadas a processos.
- IA aplicada de forma prática, principalmente quando melhora produtividade, aprendizado ou tomada de decisão.
